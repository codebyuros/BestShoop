## BestShop Landing Page

## Description
This project is a responsive landing page built using HTML and CSS.  
The purpose of this homework is to practice webpage structure, styling, and responsive design.

## Features
- Responsive design
- Navigation bar
- Hero section
- Styled buttons and sections
- Footer
- Clean layout using CSS

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone the project
2. Open `index.html` in your browser
